# Games 5/8 (TRAK-287) plan: locked at kick-off

**Issue:** TRAK-287 (spec TRAK-282). **Design:** `docs/superpowers/specs/2026-10-27-games-tab-design.md`.
**Branch:** `TRAK-287-locked-at-kick-off` from main. One PR, a draft until complete.

**Decision (Imad, 28 Oct, question tool):** the game page has no History timeline yet, and 289 builds one. So
"Locked at kick-off, with any unshared changes noted" sits in the lock's alert:

- a plan never shared reads "It wasn't shared, so only you saw it";
- a shared plan with changes left reads "N players didn't get your last changes".

Nothing new is stored: the plan and the copies are frozen at kick-off, so 289 can work out the same facts.
