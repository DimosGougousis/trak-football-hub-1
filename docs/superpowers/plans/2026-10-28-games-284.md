# Games 2/8 (TRAK-284) plan: plan step 1, opponent and goals, saved as a draft

**Issue:** TRAK-284 (spec TRAK-282). **Design:** `docs/superpowers/specs/2026-10-27-games-tab-design.md`.
**Branch:** `TRAK-284-game-plan-opponent-goals` from main. One PR, a draft until complete.

**Decision (Imad, 28 Oct):** a key player's shirt number is Arc's `input` with the number pad, not `number-field`.
Arc's own rule puts codes in `input`. Also, `number-field` always holds a number (0 to start), so an unknown shirt
number couldn't be left blank.

**Arc:** radio-group and textarea are new to Trak. Both use only React 18 APIs: `forwardRef`, `useId` and layout
effects, with no `ref` prop and no React 19 hooks. Both are free, so `PRO.md` doesn't change. Stepper, select,
input, badge and button are already in Trak.

## Tasks

1. **`game_plans`** (migration `20261028100000_game_plans.sql`): one row per match event.
   - **Columns:** `strength`, `their_formation`, `key_players` (at most 11; no names), `scouting`, and `goals` (at
     most 3). Each has a length limit. The two lists are JSON that `trak_private` checks.
   - **Access:** only the match's coach reads or writes. Writes need the games switch on and a match that isn't
     cancelled, as restrictive rules. No delete grant.
   - **Suite:** `supabase/tests/games_plans.sql`, 38 checks.
     - It runs as another coach, a coach of another academy, the admin, player A, player B, A's guardian, a child
       whose consent is pending, and anon.
     - It covers the cancelled match, the switch off (writes stop, reads stay) and every bad value.

   *Verify:* `node scripts/test-db.mjs --games-plans`. Three weakened copies of the migration must each fail it.
2. **Plan logic** (`src/lib/games/plan.ts`): the form and the saved row, rows left empty dropped, shirt numbers 1 to
   99 or blank. `loop.ts` gains "Plan not shared" (a draft) and `needsAPlan`. *Verify:* `plan.test.ts`,
   `loop.test.ts`.
3. **Game plan tab:**
   - a stepper (Opponent and goals · Line-up and jobs · Share);
   - step 1's cards: goals, strength, their line-up, scouting;
   - Save draft (loading, then Saved; a failed save keeps everything and says so).

   The game page holds the typing above the tabs. *Verify:* `game-plan-trak284.test.tsx` and `e2e/games.spec.ts`.
4. **Games home and Needs you:**
   - Open drafts lists plan drafts until kick-off, and the badge reads "Plan not shared".
   - Home's Needs you lists a shared match kicking off within 7 days: "Plan not shared · Write the plan".

   *Verify:* `games-drafts-trak284.test.tsx`.
5. **Docs:** the design doc's 284 row and decisions; the rehearsal script's Games line (TRAK-283 and TRAK-284).
