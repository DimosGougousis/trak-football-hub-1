# Games 1/8 (TRAK-283) plan: the switch, the Games tab and Games home

**Issue:** TRAK-283 (spec TRAK-282). **Design:** `docs/superpowers/specs/2026-10-27-games-tab-design.md`.
**Branch:** `TRAK-283-games-tab` from main. One PR, `TRAK-283 [scope] Games 1/8: …`, a draft until complete.

**Decision (Imad, 27 Oct):** Games home's cards follow Home's Needs you pattern (a plain surface card; in the strip,
each card is one link inside Arc's `ScrollArea`), not Arc's `card`. Arc's card is a static article that opens a
quick look: it can't be a link and it lifts on hover as if it could. Arc's badge, stepper, countdown and button
sit inside the cards.

**Arc:** tabs, empty-state and countdown are new to Trak; card, badge, button, scroll-area and stepper are already
in it. React 18: countdown takes `ref` as a prop (React 19), so it stays unset, as radar-chart does. All three
are free; `PRO.md` doesn't change.

## Tasks

1. **Switch.** A new migration widens `academy_features`' check to `('events', 'games')`. `Feature` gains
   `'games'`. Suite `supabase/tests/games_switch.sql`:
   - only a coach of an academy with the row gets `feature_on('games')`;
   - a misspelt name is refused, and app roles can't write switches;
   - deleting the row switches Games off;
   - a new academy doesn't start with Games on.
   *Verify:* `node scripts/test-db.mjs --games-switch`, `--events-switch`.
2. **Squad › Games removed for everyone.** `CoachSquadPage` keeps Players, Attributes and Availability.
   `GamesTab.tsx` and its test cases go. AGENTS.md's Squad row is updated. *Verify:* `squad-views-trak250`.
3. **Nav and routes.** `coach-places.ts` gains `games`. `CoachFrame` shows Games only when `useFeature('games')` is on:
   - sidebar: Home · Schedule · Squad · Games · Library;
   - phone: Home · Squad · Games · Library.

   `/coach/games` and `/coach/games/:eventId` sit in `RouteGuard` and `ParkedScreen unless="games"`.
   *Verify:* `coach-frame-trak259` checks the nav hidden when off and placed when on.
4. **Games home** (`CoachGames.tsx`). The squad's matches (`event_type = 'match'`, not cancelled), upcoming soonest
   first, then past ones. Sections:
   - Next game: badge, stepper, compact countdown to `starts_at`, and one button;
   - Open drafts: empty;
   - Your games: a strip of links;
   - `SquadPills`;
   - with no match, an empty state whose Add a match opens Schedule's New event with Match picked.

   `src/lib/games/loop.ts` holds the state. *Verify:* `loop.test.ts`, `games-home-trak283.test.tsx` (only this coach's
   squad's matches, soonest first, each opens its game page).
5. **Game page** (`CoachGame.tsx`). Arc tabs Logistics · Game plan · Evaluation (`?tab=`).
   - Logistics: Schedule's review rows (`EventSummary`, moved to its own file), Edit in Schedule (`?edit=`), a badge
     Shared with families or Draft, and Publish for a draft (`?publish=`).
   - Game plan and Evaluation: an empty state saying what comes there.

   *Verify:* `game-page-trak283.test.tsx`.
6. **Schedule's next step.** Publishing a match with Games on offers "Write the game plan", which opens the game
   page. *Verify:* a test in `schedule-publish-games-trak283.test.tsx`, with Games on and off.
7. **Browser.** `e2e/games.spec.ts` in the pilot config takes screenshots at 390 and 1440 px, checks no horizontal
   scroll and that the keyboard reaches every control.
