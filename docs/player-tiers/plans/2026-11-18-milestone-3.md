# Milestone 3: Messaging and the parent feed

> **For the factory:** follow `superpowers:test-driven-development`. Each task is: failing test → see it fail → minimal code → see it pass → commit.

**Goal:** every coach message, and every reply, copies all linked parents. A private one-to-one thread cannot exist. A parent can revoke contact. Parents receive a weekly feed (REQ-003, CP-05, CP-12, GR-08, GR-09).
**Architecture:** the `messaging` and `feed` packages. Recipients are decided by the server, never by the client (`ProposedSolution.md`, Decisions).
**Repository:** `player-tiers-app`. Depends on Milestone 1.

## Migration

`src/main/resources/db/migration/V3__messaging.sql`:

```sql
create table message (id uuid primary key, player_id uuid not null references account(id), author_id uuid not null references account(id), body text not null, at timestamptz not null default now());
create table message_recipient (message_id uuid not null references message(id), account_id uuid not null references account(id), primary key (message_id, account_id));
create table contact_block (player_id uuid not null references account(id), coach_id uuid not null references account(id), primary key (player_id, coach_id));
```

There is no thread-type column. Every message belongs to a player context, and its recipients are computed.

## Task 3.1–3.2: Recipient rule (REQ-003)

**Failing tests** (`src/test/java/com/academy/tiers/messaging/MessagingTest.java`):

```java
package com.academy.tiers.messaging;

import com.academy.tiers.IntegrationTestBase;
import com.academy.tiers.roster.TestAccounts;
import com.academy.tiers.verification.CoachVerificationService;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.test.web.servlet.MockMvc;
import static org.hamcrest.Matchers.hasItems;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.*;

class MessagingTest extends IntegrationTestBase {
    @Autowired MockMvc mvc;
    @Autowired TestAccounts accounts;
    @Autowired CoachVerificationService verification;

    @Test void coachMessageCopiesEveryLinkedParent() throws Exception {
        var link = accounts.activeLinkWithTwoParents(mvc, verification);
        mvc.perform(post("/messages").with(link.coachToken()).contentType("application/json")
                .content("{\"to_player_id\":\"" + link.playerId() + "\",\"body\":\"Great first touch today\"}"))
           .andExpect(status().isCreated())
           .andExpect(jsonPath("$.recipients").value(hasItems(link.playerId().toString(), link.parentId().toString(), link.secondParentId().toString())));
    }

    @Test void messageWithNoParentRecipientIsRejectedWith422() throws Exception {
        var link = accounts.activeLink(mvc, verification);
        accounts.detachAllParents(link.playerId());   // corrupt state: no parent linked
        mvc.perform(post("/messages").with(link.coachToken()).contentType("application/json")
                .content("{\"to_player_id\":\"" + link.playerId() + "\",\"body\":\"hi\"}"))
           .andExpect(status().isUnprocessableEntity()).andExpect(jsonPath("$.error").value("no_parent_recipient"));
    }

    @Test void playerReplyIsAlsoCopiedToParents() throws Exception {
        var link = accounts.activeLink(mvc, verification);
        mvc.perform(post("/messages").with(link.playerToken()).contentType("application/json")
                .content("{\"to_player_id\":\"" + link.playerId() + "\",\"body\":\"thanks coach\"}"))
           .andExpect(status().isCreated())
           .andExpect(jsonPath("$.recipients").value(hasItems(link.coachId().toString(), link.parentId().toString())));
    }
}
```

Run `./gradlew test --tests '*MessagingTest'`. Expected: 3 FAIL.

**Minimal implementation:** `MessageService.send(authorId, playerId, body)` sets the recipients to the player, every active-linked coach and every linked parent, minus the author.

- If the set has no parent, throw `NoParentRecipientException`, which maps to `422`.
- The API has no `to` field for individual accounts.

Run the same command. Expected: 3 PASS. Commit: `feat: server-side recipient rule copies parents on every message`.
