## Task 6.1: Jurisdiction configuration

Set the Greece values in `src/main/resources/application-prod.yml`:

```yaml
tiers:
  consent:
    min-age-without-verified-consent: 15   # Greece, Law 4624/2019 Art. 21 (GDPR Art. 8)
  verification:
    accepted-types: [GR_CRIMINAL_RECORD]
    renewal-warning-days: 30               # federation requirements approved by the owner, 2026-11-18
```

Add two cases to `ConsentAgeTest` with the setting at 15:

- A player who is 14 years and 364 days old with no `academy_consent_ref` gets `422 consent_required`.
- A player who turns 15 today, with no reference, gets `201`.

Run `./gradlew test --tests '*ConsentAgeTest'`. Expected: PASS. Commit: `config: Greece consent age 15 and criminal-record coach verification`.

## Task 6.3: End-to-end primary flow

**Test** (`src/test/java/com/academy/tiers/e2e/PrimaryFlowE2ETest.java`): one test runs the 15 steps of `diagrams/sequence.dot` in order through the HTTP API, and asserts at each step:

1. The admin invites a coach and the verification is active.
2. The academy admin onboards the parent. The coach onboards a player directly, the link is active, and the parent is notified. The player has Basic features before any subscription.
3. The coach assigns a drill, the player logs it, and XP rises while the attributes stay the same.
4. The coach signs a test, the attribute changes, and an audit row is written.
5. The coach sends feedback and the parent is a recipient.
6. The first milestone fires and the parent gets 1 upgrade prompt.
7. The parent checks out Premium (Stripe fake) and receives the webhook, and the tier becomes `premium`.
8. The parent opts in to wearables, a sync ingests 1 sample, and the attributes stay the same.
9. The weekly feed contains the drill, the test and the note.

Run `./gradlew test --tests '*PrimaryFlowE2ETest'`. Expected: PASS.
